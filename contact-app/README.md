# Contact Manager (vanilla JS + Bootstrap)

Simple single-page contact manager that stores data in browser `localStorage`.

Features:
- Add contact
- Edit contact
- Delete contact
- List and search contacts

How to run:
1. Open `index.html` in your browser (or use Live Server / local HTTP server).
2. Add, edit, and manage contacts. Data is stored in your browser.

Tech: HTML, CSS, Bootstrap, JavaScript

Feel free to ask for enhancements like export/import, CSV, or server sync.
